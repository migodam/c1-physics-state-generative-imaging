## Checks that look mechanically consistent

- `data.py:65-80` samples independent parent materials before noise, includes all measurements and known metadata in `inputs`, and constructs states from `(y, metadata)` with no truth argument. `data.py:86-89` fits both normalizers only on train.
- `probability.py:5-7`, `data.py:27-31`, and P0 data generation use the same real Gaussian intensity likelihood and proper prior; the dormant complex-whitening helper is not used in this pipeline. Quadrature includes cell weights in posterior mass and log evidence.
- Optimizing/checkpointing z log density is equivalent to x log density ranking for a fixed validation set when the exact logit is used, because its Jacobian term is independent of model parameters. The z-versus-x score choice is not itself a likelihood mismatch.
- The reviewed density has normalized MDN weights and full flow determinants. Cached `log_prob_z_context` / `log_prob_x_context` (`density.py:251-272`) use the same density/Jacobian algebra as the public methods. Current evaluation supplies expanded encoded context from frozen Y/S under `no_grad` (`evaluate.py:77-82`); it does not derive context from the current integration point. The helpers omit shape/device/dtype validation and require that frozen-context precondition; numerical equivalence has not been run here.
- No topology/sign labels enter the generator. `quadrant` is used only for reference/evaluation events. Continuous candidate coordinates in states are legitimate context, not category labels.
- Parent averaging in `paired_bootstrap` (`evaluate.py:23-29`) correctly averages noise replicates before resampling parents. Aggregate means are observation-based; equal replicate counts make their means equivalent to parent means. The p95 metric is explicitly the raw-observation maximum event error, not a parent-averaged MAE percentile; report that definition.
